# homebrew-tap

Homebrew tap for sk2andy tools.

## Install macpack

```bash
brew tap sk2andy/tap
brew install macpack
```

Or install directly:

```bash
brew install sk2andy/tap/macpack
```

## macpack

Universal macOS package manager for one manifest across Homebrew, Mac App Store
apps, npm/Volta tools, pnpm tools, bun tools, and uv Python tools.

Project: <https://github.com/sk2andy/macpack>
